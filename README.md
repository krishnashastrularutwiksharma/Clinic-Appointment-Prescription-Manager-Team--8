# Clinic-Appointment-Prescription-Manager-Team--8
The Clinic Appointment & Prescription Manager is a Java-based console application designed to streamline core administrative operations within a healthcare facility. Built around fundamental Object-Oriented Programming (OOP) concepts—utilizing classes, objects, custom methods, control flow loops, Scanner for user input, and ArrayList for dynamic data storage—the system effectively manages doctors, patients, appointments, prescriptions, and patient medical histories.

The architecture is structured across dedicated classes: the Doctor class tracks IDs, names, and specialties; the Patient class holds contact details, age, and personal identifiers; the Appointment class manages scheduling status along with specific dates and times; and the Prescription class records diagnostic notes and prescribed medicines linked directly to appointments. Centralizing these records, the Clinic class coordinates the overarching data lists and enforces strict validation logic—such as verifying entity existence, preventing duplicate IDs, and blocking double-booked time slots—while the Main class delivers an interactive, menu-driven interface to process user inputs.

The typical system workflow guides users sequentially: adding doctors and patients, booking and validating appointments, scheduling sessions, generating prescriptions, and retrieving comprehensive patient histories.
